## Purpose
This script triggers GPU profiling in Unreal Engine via the "ProfileGPU" console command and logs a confirmation message to the console. It serves as a simple interface for initiating profiling without additional input.

## How it is run
Command: `python area2/gpu_prof.py` in a Python environment with Unreal Engine's Python bindings. No other project files call this script, as confirmed by an empty `git grep` result for "gpu_prof.py".

## Inputs
None (no command-line arguments or input files required).

## Outputs
Console output "profilegpu issued" and GPU profiling data generated by Unreal Engine's "ProfileGPU" command (stored in engine logs, not explicitly written by this script).

None (relies on Unreal Engine's SystemLibrary API, not project files).
