## Purpose
This section dynamically loads Skyrim city references (e.g., Whiterun, Solitude) and distant terrain elements (mountains, cliffs, rocks) into Unreal Engine. It handles model conversion requests, actor spawning, and scene updates using JSON metadata files generated by external tools.

## How it is run
Registered as a Unreal editor tick callback via `start()` (executed on editor startup). Called automatically by Unreal's engine each frame. Other modules (e.g., `npc_live.py`, `tamriel_live.py`) are integrated via `area2/addons.txt` entries.

## Inputs
- JSON files: `world_*.json` (cities), `distant_refs.json` (terrain), `interiors_*.json` (interiors), `dungeon_index.json` (dungeons)
- `area2/addons.txt` (add-on module list)
- `area2/debug_flags.txt` (feature toggles like `nodistant`, `noimport`)
- Memory data via `self.pkt` (Skyrim's ctypes struct for camera/position)
- `area2/prefetch_on.txt` (enables city model prefetching)

## Outputs
- Unreal actors: `StaticMeshActor` (city buildings), `InstancedStaticMeshComponent` (distant terrain)
- Scene folders: `SkyBridge/City`, `SkyBridge/Distant`, `SkyBridge/LargeRefs`
- `area2/requests.txt` (pending model conversion requests)
- Console logs via `log()` (e.g., "city Whiterun: 142 references")

## Key functions
city_world: Loads city references from JSON files  
distant_setup: Initializes distant terrain from JSON  
tick: Main frame update loop handling camera/sky  
prefetch_cities: Background model conversion  
addons_tick: Manages add-on modules  

## Depends on
`unreal/SkyBridge/remaster_materials.py` (mesh conversion)  
`unreal/SkyBridge/ue_assets.py` (asset helper methods)  
`unreal/SkyBridge/tamriel_live.py` (Tamriel layer)  
`unreal/SkyBridge/npc_live.py` (NPCs)  

## Gotchas
- Prefetching cities requires `area2/prefetch_on.txt` to exist (opt-in)
- `nodistant` flag skips distant terrain loading (43k references)
- `noimport` flag skips model conversion imports
- Water meshes require `water_slots` fix to avoid black rendering
- Distant terrain uses instanced meshes (43k references, ~130 unique models)
