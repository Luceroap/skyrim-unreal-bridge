## Purpose
Imports models from Skyrim into Unreal Engine without requiring Skyrim or the Unreal editor to be running. Runs in headless mode (no editor window) to process converted models listed in `area2/ready.txt`, making it suitable for overnight batch processing.

## How it is run
Command line: `python tools/offline_import.py [--limit <n>] [--minutes <m>]`  
Other files calling it:  
- `Import_Assets_Offline.bat` (executes the script via Python)  
- `tools/make_local_queue.py` (lists it as a dependency)  
- `COORDINATION.md` (documents it as the offline import alternative)  
- `HANDOFF_FOR_CHATGPT.md` (describes the "Import Assets Offline (Unreal)" desktop shortcut)

## Inputs
- `--limit <n>`: Maximum models to import in this run (default: all remaining)  
- `--minutes <m>`: Stop after approximately `m` minutes (default: run until complete)  
- `area2/ready.txt`: Lists models needing import (generated by conversion tools)  
- Free RAM ≥ 8 GB (validated by script)  

## Outputs
- `area2/offline_import.log`: Primary progress log (appended during run)  
- Console output: Status messages, elapsed time, and last 4 lines of `area2/offline_import.log`  
- Unreal Engine asset imports to `/Game/Area2` (via Unreal editor)  

## Key functions
running: Checks process via tasklist.  
free_gb: Returns available RAM in GB.  
arg: Parses command-line arguments.  

## Depends on
None (only standard libraries and project structure; no other project files imported or called)

## Gotchas
- Requires closing Unreal editor (`UnrealEditor.exe`/`UnrealEditor-Cmd.exe`) by default.  
- Requires closing Skyrim (`SkyrimSE.exe`) unless `--even-if-skyrim` is used.  
- Checks for ≥8 GB free RAM before proceeding.  
- Runs via UnrealEditor-Cmd in headless mode (`-nullrhi`, `-unattended`).  
- Logs progress to `area2/offline_import.log` (not console stdout).
