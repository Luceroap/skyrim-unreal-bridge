## Purpose
Builds a skinned character FBX (armature + joined body/hands/feet mesh) from NPC skin data generated by `npc_skin.py`. Uses Skyrim's unit scaling convention (0.014287 m per unit) and specific Blender coordinate axes (-Y forward, Z up).

## How it is run
Command: `D:\blender.exe -b -P npc_blender.py -- <skin_dir> <male|female> <out.fbx>`  
Called by:
- `tools/npc_build.py` (line 103)
- `tools/npc_build_creature.py` (line 92)

## Inputs
- `skin_dir`: Directory containing `skeleton_<sex>.json` and part JSONs
- `sex`: "male" or "female" (determines skeleton key)
- `out`: Output FBX file path
- Optional arguments:
  - `--omit=<part1,part2>`: Replaces default body/hands/feet parts
  - `--creature`: Uses skeleton key instead of NPC bones
  - Additional JSON filenames (e.g., `face_<id>.json`, `gear_<id>_<n>.json`)

## Outputs
- `out.fbx`: Combined FBX file with skinned mesh and armature
- File writes: `out.fbx` (no shared memory or other files)

## Key functions
- Armature construction
- Mesh vertex/UV/material processing
- Bone weight assignment
- Mesh joining
- FBX export with Skyrim axes

## Depends on
- `npc_skin.py` (input data generation)
- Blender 3.0+ (bpy API)
- Skyrim's unit scaling convention (0.014287 m)

## Gotchas
- Windows-only Blender path (`D:\\blender.exe`)
- `SCALE = 0.014287` converts Skyrim units to meters
- `--creature` mode uses skeleton keys (e.g., `skeleton_<key>.json`)
- `--omit=body,hands,feet` replaces default parts with worn gear
- FBX export uses `-Y forward, Z up` (matches Skyrim convention)
