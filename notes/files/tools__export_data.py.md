## Purpose
Exports project data (symbols, TODOs, hardcoded paths, mesh index, model lists) as CSV files into `staging/exports/` without using LLMs. The tool processes code structure, comments, and asset references for analysis and documentation.

## How it is run
Command: `python tools/export_data.py`  
Called by `staging/README.md` (explicitly references this tool in the "EXACT CSV exports" section).

## Inputs
- `notes/index/symbols.json` (symbol index generated by `tools/make_project_index.py`)
- `notes/index/TODO.md` (TODO/FIXME comments)
- `area2/mesh_index.json` (asset-to-NIF mapping)
- `area2/ready.txt` (ready models list)
- `area2/spaced_models.txt` (skipped models due to spaces)

## Outputs
- `staging/exports/symbols.csv` (Python symbols: file, line, name, docstring)
- `staging/exports/todo.csv` (TODO/FIXME comments: file, line, text)
- `staging/exports/hardcoded_paths.csv` (Windows paths: file, line, drive, truncated path)
- `staging/exports/mesh_index.csv` (asset name → NIF path)
- `staging/exports/ready_models.csv` (converted models: model name)
- `staging/exports/spaced_models.csv` (skipped models: asset, NIF)
- `staging/exports/scripts.csv` (script files: file path, size)

## Key functions
write (CSV writer helper)

## Depends on
- `notes/index/symbols.json` (requires `tools/make_project_index.py`)
- `notes/index/TODO.md`
- `area2/mesh_index.json`
- `area2/ready.txt` and `area2/spaced_models.txt` (optional)

## Gotchas
- `symbols.csv` requires running `tools/make_project_index.py` first.
- Hardcoded paths are truncated to 200 characters in output.
- `mesh_index.csv` handles both dict and list structures.
- `ready_models.csv` and `spaced_models.csv` skip output if source files are missing.
- `hardcoded_paths.csv` uses regex to match Windows paths only.
