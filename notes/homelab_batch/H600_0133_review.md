## Finding
The function `streamed_weather` may produce incorrect fog values when `fog_far` is zero, leading to a division by zero in the calculation `500.0 / fog_far`.

## Evidence
- unreal/SkyBridge/live_bridge.py:361 - fog = 0.003 if fog_far <= 0 else max(0.002, min(0.05, 0.001 + 500.0 / fog_far))

## Suggested fix
Replace the condition `fog_far <= 0` with `fog_far <= 0.0` to ensure that `fog_far` is treated as a float and avoid division by zero.

## Validation needed
Test the function with `fog_far` values of zero and negative to confirm that the fix resolves the division by zero issue.
