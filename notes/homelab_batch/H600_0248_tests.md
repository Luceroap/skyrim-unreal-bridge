## Finding
The function `_apply_pose` applies bone transforms to an NPC's skeletal mesh based on streamed pose data. It uses a combination of rotation and translation calculations to position bones in the correct space. However, the logic for handling bone transforms may not account for all edge cases, such as missing bones or incorrect scaling.

## Evidence
- unreal/SkyBridge/npc_live.py:572 - b = bones.get(name)

## Suggested fix
Test Case 1: Missing Bone Handling
Input: A bone name that does not exist in the `bones` dictionary.
Expected Result: The function should skip applying the transform for that bone without raising an error.

Test Case 2: Bone Scaling
Input: A bone with a defined scale in `scales`.
Expected Result: The bone's transform should use the specified scale from `scales`.

Test Case 3: Batch Mode Pose Application
Input: A valid pose with multiple bones in batch mode.
Expected Result: All valid bone transforms should be applied in a single batch call to `apply_pose`.

## Validation needed
For Test Case 1, verify that the function does not raise an error when a bone is missing. For Test Case 2, ensure that the bone's scale is correctly applied. For Test Case 3, confirm that the batch mode correctly applies all valid bone transforms in one call.
