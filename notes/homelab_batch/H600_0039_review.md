## Finding
The code assumes that the packet version is always at least 2 when drawing the HUD, but does not handle cases where the packet version is less than 2. This can lead to incorrect HUD rendering or crashes if the packet data is not properly aligned with the expected format.

## Evidence
- remaster_watch.py:291 - hud.frame(v, visible and v[1] >= 2)

## Suggested fix
Check the packet version before accessing data that depends on it. For example, ensure that `v[1] >= 2` before attempting to draw the HUD.

Test the application with a packet version less than 2 to confirm that the HUD is not drawn incorrectly or that the application crashes.
