# review: unreal/SkyBridge/live_bridge.py:63 __init__

Local-model review lead; NOT independently verified or applied.

## Finding
The code assumes that the `unreal.get_editor_subsystem` function will always return valid instances of `UnrealEditorSubsystem` and `LevelEditorSubsystem`, but it does not handle cases where these subsystems might not be available or initialized at the time of the call.

## Evidence
- unreal/SkyBridge/live_bridge.py:76 - self.ues = unreal.get_editor_subsystem(unreal.UnrealEditorSubsystem)

## Suggested fix
Wrap the calls to `unreal.get_editor_subsystem` in a try-except block to handle potential exceptions when the subsystems are not available.

## Validation needed
The developer should run the script in the Unreal Editor and verify that it does not crash when the subsystems are not available or initialized.
