# tests: unreal/SkyBridge/weather_fx.py:58 _material

Local-model review lead; NOT independently verified or applied.

## Finding
The function `_material` is responsible for creating or rebuilding a material asset. If the asset already exists and a rebuild is requested, it deletes all existing material expressions before returning the material. This may cause unintended behavior if the material is currently in use by other actors or systems, as the deletion could disrupt ongoing rendering or visual effects.

## Evidence
- unreal/SkyBridge/weather_fx.py:67 - mel.delete_all_material_expressions(m)

## Suggested fix
Before deleting all material expressions, check if the material is currently in use by any actors or systems. If it is, delay the deletion until the material is no longer needed. This ensures that ongoing visual effects are not disrupted.

## Validation needed
Mock the material usage check to ensure that the function correctly identifies whether the material is in use. In-game verification would involve observing whether visual effects are disrupted during a rebuild.
