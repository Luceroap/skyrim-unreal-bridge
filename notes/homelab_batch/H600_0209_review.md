## Finding
The function `parse_bones` may fail to correctly parse bone data if the number of bones (`nb`) does not match the expected number of names (`n`). This mismatch could lead to incorrect or incomplete bone data being parsed.

## Evidence
- unreal/SkyBridge/npc_live.py:123 - for ni, par, x, y, z, qx, qy, qz, qw in BONE.iter_unpack(buf[o + 180:o + 180 + nb * 32]) if ni < n

## Suggested fix
Ensure that the number of bones (`nb`) matches the number of names (`n`) before parsing. If they do not match, raise an error or handle the discrepancy explicitly.

## Validation needed
Verify that the number of bones parsed matches the number of names provided. A developer should run a test with a known valid and invalid bone count to confirm the fix.
