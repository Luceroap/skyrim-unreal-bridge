# review: unreal/SkyBridge/live_bridge.py:329 set_interior

Local-model review lead; NOT independently verified or applied.

## Finding
The function `set_interior` hides all outdoor actors unconditionally when `interior` is True, which may lead to unintended visibility changes if some outdoor actors are required to be visible even in interior cells.

## Evidence
- unreal/SkyBridge/live_bridge.py:337 - outdoor = ("SkyBridge/Terrain", "SkyBridge/Water", "SkyBridge/LargeRefs")

## Suggested fix
Refactor the logic to allow selective hiding of outdoor actors based on specific criteria, rather than hiding all of them unconditionally.

## Validation needed
Test the function with a scenario where some outdoor actors should remain visible in interior cells.
