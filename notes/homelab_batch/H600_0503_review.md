# review: start_bridge.py:247 remaster_off

Local-model review lead; NOT independently verified or applied.

## Finding
The function `remaster_off` may fail to correctly restore the Unreal window's original state because it uses a hardcoded set of flags to modify the window's extended style. This could lead to unintended side effects if the original extended style contained other flags not accounted for in the mask.

## Evidence
- start_bridge.py:253 - ex = user32.GetWindowLongW(ue, -20)

## Suggested fix
Instead of using a hardcoded mask, preserve the original extended style and only remove the specific flags related to the overlay (e.g., `0x20`, `0x80000`, `0x80`, `0x08000000`) by using bitwise operations that isolate and retain the rest of the flags.

## Validation needed
Test the function with a Unreal window that has additional extended style flags to ensure that only the intended flags are removed and that the original window behavior is preserved.
