# review: remaster_watch.py:115 show

Local-model review lead; NOT independently verified or applied.

## Finding
The `show` function does not properly handle the case when the window is being hidden (`on=False`). Specifically, it does not ensure that the window is fully hidden, which could lead to the window remaining partially visible or not being hidden at all in certain scenarios.

## Evidence
- remaster_watch.py:118 - user32.ShowWindow(self.hwnd, 4 if on else 0)                 # SW_SHOWNOACTIVATE / SW_HIDE

## Suggested fix
Ensure that the window is hidden correctly by using `SW_HIDE` (value 0) and also explicitly setting the window's position and size to zero when hiding the window, similar to how it is done when showing the window.

## Validation needed
Test the `show` function with `on=False` to confirm that the window is fully hidden and not left partially visible.
