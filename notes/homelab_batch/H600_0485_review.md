Local-model review lead; NOT independently verified or applied.

## Finding
The function ue_only() does not ensure that Skyrim is running before attempting to minimize it. If Skyrim is not running, the code will attempt to minimize a non-existent window, which could cause an error or unexpected behavior.

## Evidence
- start_bridge.py:101 - sky, ue = find_window("SkyrimSE.exe"), find_window("UnrealEditor.exe")

## Suggested fix
Add a check to ensure that Skyrim is running before attempting to minimize it. For example, use the running() function defined earlier in the code to verify that 'SkyrimSE.exe' is running.

## Validation needed
The developer should run the function ue_only() in a scenario where Skyrim is not running and confirm that no error occurs and that the code correctly handles the absence of the Skyrim window.
