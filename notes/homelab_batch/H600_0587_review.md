# review: tools/editor_watchdog.py:114 last_session_log

## Finding
The function last_session_log() may return a log file that belongs to a currently running editor session, which could lead to incorrect crash detection.

## Evidence
- tools/editor_watchdog.py:117 - logs = glob.glob(os.path.join(play.LOGS, "SkyBridge*.log"))

## Suggested fix
Filter logs to exclude those from currently running editor processes to ensure only logs from completed sessions are considered.

## Validation needed
Check if the returned log file corresponds to a completed session by verifying that no editor process is currently running with the same log file name.
