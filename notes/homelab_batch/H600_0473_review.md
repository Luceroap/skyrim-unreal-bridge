# review: start_bridge.py:21 stream_frame

Local-model review lead; NOT independently verified or applied.

## Finding
The function stream_frame does not handle the case where the shared memory mapping fails after the file mapping handle is successfully obtained. This can lead to a resource leak if the MapViewOfFile call fails but the OpenFileMappingW call was successful.

## Evidence
- start_bridge.py:26 - h = kernel32.OpenFileMappingW(4, False, "Local\\SkyrimUnrealBridge_v1")

## Suggested fix
Add error checking after the kernel32.MapViewOfFile call to ensure that the mapping was successful. If it fails, close the file mapping handle and return None.

## Validation needed
Test the function with a scenario where the shared memory mapping fails after the file mapping handle is successfully obtained to ensure that the handle is properly closed and the function returns None.
