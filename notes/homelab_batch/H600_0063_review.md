## Finding
The function 'write_obj' writes vertex indices in the OBJ file with incorrect formatting, which may cause parsing issues in some OBJ viewers. The format 'f %d/%d %d/%d %d/%d' repeats the same vertex index twice per line, which is not standard for OBJ files.

## Evidence
- tools/nif2obj.py:199 - f.write("f %d/%d %d/%d %d/%d\n" % (a + off, a + off, b + off, b + off, c + off, c + off))

## Suggested fix
Change the format string to 'f %d/%d %d/%d %d/%d' to use unique vertex indices for each position in the face definition.
