# review: unreal/SkyBridge/tamriel_live.py:388 chunk_step

Local-model review lead; NOT independently verified or applied.

## Finding
The function chunk_step may fail to load terrain chunks correctly when multiple chunks are ready at the same time, as it returns immediately after processing the first chunk. This can lead to incomplete terrain loading.

## Evidence
- unreal/SkyBridge/tamriel_live.py:435 - return True                                              # one import per tick

## Suggested fix
Remove the early return statement to allow processing of all ready chunks in a single tick.

## Validation needed
Verify that multiple terrain chunks are loaded correctly in a single tick after modifying the function to remove the early return.
