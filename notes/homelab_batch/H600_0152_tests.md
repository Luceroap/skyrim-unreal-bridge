# tests: unreal/SkyBridge/live_bridge.py:625 spawn_some

Local-model review lead; NOT independently verified or applied.

## Finding
The function `spawn_some` processes a queue of objects to spawn in the Unreal editor, but it lacks explicit checks for the validity of the `model` parameter passed to `self.asset_name(model)` and `self.mesh(name)`. This could lead to unexpected behavior if invalid or missing models are processed.

## Evidence
- unreal/SkyBridge/live_bridge.py:639 - name = self.asset_name(model)

## Suggested fix
Add a check to ensure that `model` is not `None` or empty before calling `self.asset_name(model)` and `self.mesh(name)`. If `model` is invalid, skip processing that entry in the queue.

## Validation needed
Mock the `self.asset_name` and `self.mesh` methods to return `None` for invalid models and verify that the function skips processing such entries. In-game verification should confirm that no actors are spawned for invalid models.
