## Finding
The remapper function may incorrectly handle form IDs when the plugin name is not found in the MASTERS list. This could lead to incorrect runtime form IDs being generated, potentially causing data mismatches or failures in loading assets.

## Evidence
- tools/distant_world.py:171 - idx = [order.index(m) if m in order else 0xFF for m in mast] + [order.index(name.lower())]

## Suggested fix
Replace `order.index(name.lower())` with a check to ensure `name.lower()` exists in `order` before calling `index`. If not found, raise an error or assign a default value.

Test the remapper function with a plugin name that is not in the MASTERS list to confirm that it either raises an error or assigns a default value correctly.
