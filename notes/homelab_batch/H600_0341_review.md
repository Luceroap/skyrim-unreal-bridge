## Finding
The code assumes that the 'sky_dome' attribute exists on the 'live' object, but does not handle the case where it is missing during the attachment step. This can lead to a failure when attaching the spawned actor to the sky dome.

## Evidence
- unreal/SkyBridge/night_sky.py:108 - if getattr(live, "sky_dome", None):

## Suggested fix
Replace the 'getattr' check with a direct check for the existence of 'sky_dome' on the 'live' object before attempting to attach. For example, use 'if hasattr(live, "sky_dome")' instead.

## Validation needed
Test the function with a 'live' object that does not have a 'sky_dome' attribute to ensure that the attachment step is skipped without raising an exception.
