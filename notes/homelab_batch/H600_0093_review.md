# review: unreal/SkyBridge/land_terrain_live.py:276 _camera_skyrim

Local-model review lead; NOT independently verified or applied.

## Finding
The function _camera_skyrim() returns a fixed fallback value (23000.0, -6000.0) in case of an exception, which may not accurately represent the camera position when the exception occurs. This could lead to incorrect behavior in the terrain logic that depends on the camera's position.

## Evidence
- unreal/SkyBridge/land_terrain_live.py:281 - return 23000.0, -6000.0

## Suggested fix
Instead of returning a fixed fallback value, consider logging the exception and returning a default value that is more likely to be safe or representative of a typical camera position.

## Validation needed
The developer should test the function under scenarios where the exception is triggered and verify that the fallback value does not cause incorrect behavior in the terrain logic.
