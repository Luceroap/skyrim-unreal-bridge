# tests: tools/distant_world.py:106 read_water

Local-model review lead; NOT independently verified or applied.

## Finding
The `read_water` function processes Skyrim's data files to extract water-related information from exterior cells. It checks for the 'has water' flag (0x02) in the DATA record and uses the XCLW height if present. However, the function may not correctly handle cases where the XCLW height is invalid or missing, leading to incorrect or incomplete water data being stored in the `cells` dictionary.

## Evidence
- tools/distant_world.py:142 - if has_water: cells[xclc] = xclw

## Suggested fix
Add a check to ensure that `xclw` is valid before assigning it to `cells[xclc]`. This will prevent invalid or missing XCLW values from being stored in the output dictionary.

## Validation needed
To validate this fix, a developer should mock a Skyrim data file with a valid XCLW value and a flag indicating the presence of water. They should then run the `read_water` function and verify that the `cells` dictionary is updated correctly with the XCLW value. Additionally, a test case with an invalid or missing XCLW value should be created to ensure that the function does not store incorrect data.
