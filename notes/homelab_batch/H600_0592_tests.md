## Finding
The `classify` function may not correctly detect 'clean' exits if the log contains 'QUIT_EDITOR' but also includes other crash-related markers later in the log. This could lead to misclassification of the session type.

## Evidence
- tools/editor_watchdog.py:159 - quit_ = [l for l in lines if "QUIT_EDITOR" in l]

## Suggested fix
Ensure that 'QUIT_EDITOR' is the last relevant log entry before the log ends, and that no crash markers appear after it. For example, if a log ends with 'QUIT_EDITOR' but also contains a 'Critical error' line later, the function should return 'crash', not 'clean'.
