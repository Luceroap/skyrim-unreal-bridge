# review: unreal/SkyBridge/npc_live.py:46 mat_to_quat

Local-model review lead; NOT independently verified or applied.

## Finding
The mat_to_quat function incorrectly computes the quaternion components, leading to incorrect rotation values for certain input matrices.

## Evidence
- unreal/SkyBridge/npc_live.py:47 - tr = m[0] + m[4] + m[8]

## Suggested fix
The indices used to access the matrix elements are incorrect for a 4x4 matrix. The correct indices for the diagonal elements of a 4x4 matrix are m[0], m[5], m[10], not m[0], m[4], m[8].
