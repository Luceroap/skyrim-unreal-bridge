# review: unreal/SkyBridge/remaster_materials.py:663 hair_material

Local-model review lead; NOT independently verified or applied.

## Finding
The hair_material function does not properly set the opacity mask for the material, which could lead to incorrect rendering of the hair's transparency.

## Evidence
- unreal/SkyBridge/remaster_materials.py:683 - m.set_editor_property("opacity_mask_clip_value", 0.35)

## Suggested fix
Set the opacity mask explicitly using a texture sample or parameter, similar to how the base color is set with a texture sample parameter.

## Validation needed
Verify that the material renders with the correct opacity mask when applied to a hair mesh in the Unreal Engine.
