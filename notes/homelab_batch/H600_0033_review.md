## Finding
The function `draw_prompt` does not handle the case where the input `text` contains more than one tab character (`	`). This can lead to incorrect parsing of the `verb` and `name` variables, resulting in incorrect rendering of the activation prompt.

## Evidence
- remaster_watch.py:216 - verb, _, name = text.partition("\t")

## Suggested fix
Replace the line `verb, _, name = text.partition("\t")` with `parts = text.split("\t", 1); verb, name = (parts[0], parts[1]) if len(parts) > 1 else ("", text)`. This ensures that only the first tab character is used for splitting, and the rest of the string is treated as part of the name.

## Validation needed
Test the function with inputs containing multiple tab characters, such as `"E	Aela	the	Huntress"`, and verify that the prompt is rendered correctly with `verb = "E"` and `name = "Aela	the	Huntress"`.
