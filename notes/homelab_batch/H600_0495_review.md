## Finding
The function `focus(hwnd)` attempts to set the foreground window using `SetForegroundWindow`, but it does not ensure that the window is active or visible before attempting to set focus. This can lead to failures if the window is not in a state that allows it to receive focus.

## Evidence
- start_bridge.py:197 - user32.SetForegroundWindow(hwnd)

## Suggested fix
Ensure the window is visible and active before calling `SetForegroundWindow`. This can be done by checking the window's state using `IsWindowVisible` and `IsWindow` before attempting to set focus.

## Validation needed
Test the function with a window that is not visible or not active to confirm that it now correctly handles such cases.
