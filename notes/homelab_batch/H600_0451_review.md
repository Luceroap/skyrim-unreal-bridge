# review: unreal/SkyBridge/weather_fx.py:288 _set

Local-model review lead; NOT independently verified or applied.

## Finding
The function _set does not handle the case where the material parameter name (name) is not present in the material (mpc). This can lead to an exception being raised when trying to set a parameter that does not exist in the material.

## Evidence
- unreal/SkyBridge/weather_fx.py:294 - unreal.MaterialLibrary.set_scalar_parameter_value(_world(), _st["mpc"], name, value)

## Suggested fix
Before attempting to set the parameter, check if the parameter exists in the material. If it does not exist, log a warning and return early.

## Validation needed
Verify that the material (mpc) contains the parameter (name) that is being set. If the parameter is not present, the function should not attempt to set it.
