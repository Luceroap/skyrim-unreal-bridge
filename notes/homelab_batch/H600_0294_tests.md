However, the logic for identifying these actors may not account for all possible scenarios, such as when multiple scripts are holding the same actor or when actors are not properly tracked in the `_npc_caps` or `_sky_cap` attributes.

## Evidence
- unreal/SkyBridge/atmosphere.py:304 - held = [c[0] for c in getattr(live, "_npc_caps", [])]

Test cases should ensure that the function correctly identifies and removes only the stray `SceneCapture2D` actors that are not being held by any script.
