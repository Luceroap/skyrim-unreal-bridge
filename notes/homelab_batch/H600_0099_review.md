## Evidence
- unreal/SkyBridge/land_terrain_live.py:319 - z = 0.0 if STATE["swapped"] else -SINK * U

Change the line to `z = -SINK * U if STATE["swapped"] else 0.0` to ensure the new terrain is positioned correctly relative to the old terrain when `swap` is active.
