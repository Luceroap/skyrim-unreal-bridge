# review: tools/debug/walk_check_lib.py:17 limb_angles

Local-model review lead; NOT independently verified or applied.

## Finding
The function `limb_angles` may produce incorrect angle calculations due to an incorrect use of the trace matrix. The calculation assumes that the trace of the rotation matrix corresponds to the cosine of the angle between the current and rest pose, but this is only valid for a single rotation axis. The formula used does not correctly account for the full rotation angle in 3D space.

## Evidence
- tools/debug/walk_check_lib.py:28 - rel[0] + rel[4] + rel[8] - 1

## Suggested fix
Replace the formula for calculating the angle with a more accurate method that computes the angle between the current and rest pose using the full rotation matrix. For example, use the axis-angle decomposition or the Euler angles derived from the rotation matrix.

## Validation needed
The developer should validate the angle calculation by comparing it with a known correct implementation or by visually inspecting the limb movements in the game.
