## Finding
The function does not properly handle the case where the new LOD actor is not yet created when 'on' is set to True. This can lead to incorrect visibility settings and improper terrain swapping.

## Evidence
- unreal/SkyBridge/land_terrain_live.py:400 - new_lod = _lod_actor() if on else STATE["lod"]

## Suggested fix
Ensure that the new LOD actor is created before attempting to set its visibility. This can be done by explicitly calling the function to create the LOD actor before setting visibility.

## Validation needed
Verify that the '_lod_actor()' function is called and returns a valid LOD actor before attempting to set its visibility in the 'swap' function.
