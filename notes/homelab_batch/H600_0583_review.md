## Finding
The function `focus_skyrim()` may fail to correctly focus on the Skyrim window if multiple instances of `skyrimse.exe` are running, or if the first window in the `found` list is not the intended one.

## Evidence
- tools/editor_watchdog.py:106 - if found:

## Suggested fix
Instead of using the first element in the `found` list (`found[0]`), iterate through all found windows and select the one that is most likely to be the active Skyrim window (e.g., based on window title or other criteria).

## Validation needed
Test the function with multiple `skyrimse.exe` windows open to ensure the correct one is focused.
