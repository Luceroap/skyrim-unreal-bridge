# review: unreal/SkyBridge/ue_assets.py:94 hidden_material

Local-model review lead; NOT independently verified or applied.

## Finding
The function `hidden_material` creates a material with a blend mode of BLEND_MASKED but does not set the opacity mask value explicitly. This may lead to unexpected rendering behavior if the material is used without an opacity mask texture.

## Evidence
- unreal/SkyBridge/ue_assets.py:99 - m.set_editor_property("blend_mode", unreal.BlendMode.BLEND_MASKED)

## Suggested fix
Set the opacity mask value explicitly using `mel.set_material_property` or ensure an opacity mask texture is used with the material.

## Validation needed
Verify that the material renders correctly with the BLEND_MASKED blend mode by testing it in the Unreal Editor with and without an opacity mask texture.
