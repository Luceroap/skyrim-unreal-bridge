## Finding
The code may fail to correctly parse vertex UV coordinates for certain NIF versions due to an incorrect use of the 'e' format specifier in struct.unpack_from.

## Evidence
- tools/nif2obj.py:165 - u, v = struct.unpack_from("<2e", data, base + uvoff)

## Suggested fix
Replace the 'e' format specifier with 'f' to correctly parse floating-point UV coordinates, as 'e' is for half-precision floats and may not match the actual data format used in the NIF file.

## Validation needed
Test the parser with a NIF file that contains UV data and verify that the UV coordinates are correctly extracted and applied to the output OBJ file.
