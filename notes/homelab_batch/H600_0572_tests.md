## Finding
The function `dump_dungeons` processes interior cells and assigns lighting based on the presence of XCLL data or lighting templates. However, the logic for handling lighting may not account for all edge cases, such as when a cell has neither XCLL data nor a valid lighting template, potentially leading to incorrect or missing lighting assignments.

## Evidence
- tools/distant_world.py:319 - light = [c.get("ambient"), c.get("directional"), c.get("fog")]

## Suggested fix
Add a fallback mechanism to assign default lighting values if neither XCLL data nor a lighting template is available. For example, if `light` is empty or contains only `None` values, assign a default ambient, directional, and fog value.

## Validation needed
