## Finding
The function `auto_tier` returns 'medium' for certain GPU scores and VRAM thresholds, but does not account for the 'ultra' tier in those conditions. This could lead to suboptimal quality settings being applied when higher tiers are supported.

## Evidence
- unreal/SkyBridge/atmosphere.py:104 - if score >= 100 and vram >= 15: return "medium"

## Suggested fix
Update the condition to return 'ultra' when appropriate, based on the GPU score and VRAM. For example, change the line to: `if score >= 100 and vram >= 15: return "ultra"`.
