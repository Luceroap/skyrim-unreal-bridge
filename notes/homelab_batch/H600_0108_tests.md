Local-model review lead; NOT independently verified or applied.

## Finding
The `swap` function modifies the visibility and location of actors based on the `on` parameter, but it does not ensure that the visibility and location changes are correctly applied in all scenarios, especially when the `new_lod` actor is not present.

## Evidence
- unreal/SkyBridge/land_terrain_live.py:404 - a.static_mesh_component.set_visibility(not (on and new_lod is not None))

## Suggested fix
Test Case 1: When `on=True` and `new_lod` is not present, the function should not set the visibility of the `lod` actors. Expected: `lod` actors remain invisible.

Test Case 2: When `on=False`, the function should lower the new tiles by `SINK * U` units and hide the new terrain. Expected: New tiles are at `z = -SINK * U` and not visible.

Test Case 3: When `on=True` and `new_lod` is present, the function should set the visibility of the `new_lod` actor to `True`. Expected: `new_lod` actor is visible.

## Validation needed
Mock the presence and absence of `new_lod` and verify the visibility and location of the actors in the game. Use in-game verification to ensure that the terrain behaves as expected when the `swap` function is called with different values of `on`.
