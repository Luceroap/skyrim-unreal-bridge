# review: play.py:50 free_gb

Local-model review lead; NOT independently verified or applied.

## Finding
The function `free_gb` incorrectly calculates the amount of available physical memory in gigabytes. It uses `m.ap` which represents the total physical memory, not the available memory.

## Evidence
- play.py:54 - m = MS(); m.l = ctypes.sizeof(MS); ctypes.windll.kernel32.GlobalMemoryStatusEx(ctypes.byref(m))

## Suggested fix
Replace `m.ap` with `m.av` to correctly retrieve the available physical memory.
