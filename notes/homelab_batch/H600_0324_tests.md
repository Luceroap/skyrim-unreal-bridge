## Finding
The `clear(live)` function is responsible for removing all grass actors and related state from the `live` instance. However, it does not fully reset the state, as some keys like `mat_done`, `t_missing`, `t_ws`, and `err` are not cleared. This could lead to inconsistent state if `clear` is called multiple times or if the grass system is reinitialized after a clear.

## Evidence
- unreal/SkyBridge/grass_live.py:227 - st.update(actors={}, built={}, tiles={}, key=None, dirty=set(), cells={})

## Suggested fix
Update the `clear(live)` function to also reset the `mat_done`, `t_missing`, `t_ws`, and `err` keys in the `st` dictionary. This ensures that all state is properly cleared after a call to `clear`.

After implementing the fix, a developer should verify that calling `clear(live)` results in an empty `st` dictionary. This can be done by inspecting the `live._grass` state after the call to ensure all keys are reset.
