# tests: tools/editor_watchdog.py:114 last_session_log

Local-model review lead; NOT independently verified or applied.

## Finding
The function `last_session_log` retrieves the most recently modified log file from the `play.LOGS` directory. However, it does not verify whether the log file corresponds to a session that ended due to a crash, which is a key condition for relaunching the editor. This could lead to incorrect relaunch decisions if the log file is from a clean exit or unrelated process.

## Evidence
- tools/editor_watchdog.py:117 - logs = glob.glob(os.path.join(play.LOGS, "SkyBridge*.log"))

## Suggested fix
Add a check to ensure that the selected log file corresponds to a session that ended in a crash. For example, verify that the log contains a specific crash indicator string (e.g., 'Critical error' or 'RequestExit(1)').

## Validation needed
Mock the `glob.glob` function to return a list of log files, including one with a crash indicator and one without. Verify that the function returns only the log file with the crash indicator.
