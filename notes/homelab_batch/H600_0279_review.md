# review: unreal/SkyBridge/atmosphere.py:70 detect_gpu

Local-model review lead; NOT independently verified or applied.

## Finding
The function `detect_gpu` may fail to correctly parse the `HardwareInformation.qwMemorySize` value if it is not in bytes format and not a string. This could lead to incorrect VRAM values being returned.

## Evidence
- unreal/SkyBridge/atmosphere.py:86 - mem = int.from_bytes(mem, "little") if isinstance(mem, bytes) else int(mem)

## Suggested fix
Ensure that `mem` is always treated as a byte string before conversion. Replace the line with: `mem = int.from_bytes(mem, 'little') if isinstance(mem, bytes) else int(mem.encode('utf-8'))`.

## Validation needed
Test the function on systems where the `HardwareInformation.qwMemorySize` value is not in bytes format and verify that the VRAM is correctly parsed.
